The user wants a sign-in-required, 2D 1v1 BedWars game against a bot with blue and orange teams and normal difficulty. Each match starts after choosing one of five maps. Only iron is collected, generated at one iron per 50 ms; the match shop contains only blocks, swords, and axes. The lobby has Play, Shop, and Settings. D-tier kits are free; C/B/A/S unlocks cost 20/30/40/50 coins. Four separate 10-coin crates unlock nonduplicate sword, kit, block, and axe skins. Daily trivia is removed.

**Why:** The user explicitly requested a simple, reliable playable game and most recently narrowed matches to fast iron-only rounds with account-wide sign-in.

**How to apply:** Preserve these scope limits when extending gameplay. Do not add diamond or emerald resources, armor, ranged weapons, multiplayer, or guest play without a new request.

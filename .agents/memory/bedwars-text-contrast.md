description: Readability guidance for the BedWars red-and-black visual theme

The user explicitly wants every text element dark red, including text on dark surfaces. Apply the same dark-red text color across the site.

**Why:** The user repeated and emphasized this color requirement after a readability-focused alternative was tried.

**How to apply:** Do not override this with light text or semantic text colors unless the user asks.
